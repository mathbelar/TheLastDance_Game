# The Last Dance 

## Integrantes
- Matheus Belarmino
- Diogo Diniz
- Pedro Berganton

## Sobre o Jogo
O jogador controla um personagem fixo que defende uma barreira contra 
ondas infinitas de zumbis. O objetivo é sobreviver o máximo possível 
eliminando inimigos e protegendo a barreira.

## Controles
- **Mira:** Mouse
- **Atirar:** Clique esquerdo

## Funcionalidades (Sprint 2)
- Player fixo com mira e tiro no mouse
- Inimigos spawnando com animações (walk e idle)
- Inimigos atacam a barreira continuamente
- Partículas de sangue ao acertar inimigos
- HUD com vida da barreira e dinheiro
- Tela de Game Over com botão de restart
- Pós processamento (bloom, vignette, color adjustments)
